# AI Tool Collection | 精选AI生产力工具集

[![GitHub Pages Deploy](https://github.com/dorcasxu/AI-Tool-Collection/actions/workflows/deploy.yml/badge.svg)](https://github.com/dorcasxu/AI-Tool-Collection/actions)

这是一个精心整理的个人常用AI生产力工具集合，旨在分享和发现那些能够显著提升工作效率的前沿AI工具。

> **在线访问地址：[https://dorcasxu.github.io/AI-Tool-Collection/](https://dorcasxu.github.io/AI-Tool-Collection/)**

## 📖 关于项目

本项目是一个静态网页，用于展示一份持续更新的AI工具列表。列表涵盖了**大模型、AI编程、AI Agent、AI绘画、AI视频、AI搜索**等多个实用领域。

创建这个项目的初衷是为了方便个人查阅和与他人分享，希望能帮助更多人找到适合自己的AI助手。

## 🚀 技术与部署

*   **前端**: 纯粹使用 `HTML` 和 `CSS` 构建，保证页面加载速度和兼容性。
*   **部署**: 通过 **GitHub Actions** 自动部署到 **GitHub Pages**。每当 `main` 分支有更新时，工作流会自动触发，将最新的内容发布到线上。

## 🤝 如何贡献

这个列表的价值在于社区的共同维护。如果你有优秀的AI工具推荐，或者发现列表中的信息有误或可以改进，我们非常欢迎你的贡献！

你可以通过以下方式参与：

1.  **提交 Issue**: 如果你有任何建议或发现问题，请在 [**Issues**](https://github.com/dorcasxu/AI-Tool-Collection/issues) 页面新建一个议题进行讨论。
2.  **发起 Pull Request**:
    *   **Fork** 本仓库到你的账户下。
    *   在新的分支中修改 `index.html` 文件，添加或更新工具信息。
    *   创建一个 **Pull Request**，并清晰地描述你的修改内容。

感谢所有为此项目做出贡献的朋友！
